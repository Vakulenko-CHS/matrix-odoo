# T-COST-01 — собівартість у «Пошук: Товар»

Канон: [Low §1 — Собівартість дивана](../vadim/stosovno-zmin-u-bazi.md#1-відображення-собівартості-дивана).

## Формула

Для `product.product`:

1. BOM: `product_id` = варіант, інакше template-BOM (`product_tmpl_id`, `product_id` = false), `type=normal`.
2. **Матеріали:** `Σ bom_line.product_qty × component.standard_price`.
3. **Робота (штучна):** `Σ operation.x_studio_piece_rate_2` на `mrp.routing.workcenter`.
4. **Собівартість** = матеріали + робота.

`standard_price` і piece-rate можуть бути 0 — сума все одно рахується; повнота залежить від цін клієнта.

## Odoo (Studio)

| Артефакт | Значення |
|----------|----------|
| Поле | `product.product.x_studio_bom_cost` (float, compute, не stored) |
| **Рядки КП/замовлення** | inherit `sale.order.form` (2729) — колонка **«Собівартість»** (`sale.order.line.x_studio_product_bom_cost` related) |
| **Пошук товару** | inherit `product.product.list` (479) — колонка **«Собівартість»** у **Шукати більше…** |
| Каталог SO (кнопка «Каталог») | inherit kanban catalog (486) — підпис «Вартість (собі):» (у Odoo 19 тут картки, не таблиця) |
| Форма товару | inherit `product.product.view.form.normalized` (483) — після `standard_price` |
| Група | `sales_team.group_sale_manager` (адмін бачить; звичайний sales — ні) |

## Де це в Odoo (меню та екрани)

Бачать лише користувачі з правами **керівника продажів** (типово адмін Даніл).

| № | Шлях у меню | Що побачити |
|---|-------------|-------------|
| **1** (головне) | **Продажі** → **Замовлення на продаж** (або **Комерційні пропозиції**) → відкрити документ (напр. S00272) → вкладка **Рядки замовлення** | Колонка **«Собівартість»** у таблиці рядків — **одразу після «Ціна одиниці»** (порівняння продажу й BOM). Якщо колонки немає: **⋮** над таблицею → увімкнути **Собівартість**. |
| **2** | КП → рядок → **Товар** → **Шукати більше…** → **Пошук: Товар** (список **шаблонів**) | Окрема колонка **«Собівартість»** (BOM). Колонка **«Вартість»** 0,00 — це штатне поле Odoo (`standard_price` товару), **не** BOM; можна вимкнути в ⋮. |
| **3** | КП → клік по **назві/посиланню товару** в рядку → картка **Товар** (загальна інформація) | Поле **«Собівартість»** поруч із **продажною ціною** у блоці цін. |
| **4** (рідко) | У тій же сітці рядків КП, над таблицею, **Додати товар** → **Каталог** (не на всіх екранах помітно) | Картки з підписом **Собівартість** під ціною. |
