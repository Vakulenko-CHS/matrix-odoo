# T-PAY-01 — зарплата вантажників / прибиральниць

Канон: [§2 Вадим](../vadim/stosovno-zmin-u-bazi.md#2-нарахування-зарплати-вантажникам-та-прибиральницям).

## Odoo (matrix14, read-only 2026-11-16)

| Що | Стан |
|----|------|
| Модулі | `hr`, `hr_payroll`, `hr_payroll_account`, `account`, `hr_work_entry`, `l10n_ua` — **installed** |
| Зарплата цехів | **Worker Pay** — piece rate з MO (`src/tools/payroll/`, T-QAL Worker для ВТК) |
| Типи структур | `Employee`, `Worker`, `Робітник` |
| Структури | `Regular Pay`, `Worker Pay` |
| Вантажники в Employees | 3: Саша Комірник, Саша ватажник 1, Саша вантажник 2 — посада **вантажники**, `hr.version` wage **1300** / **1454**, тип **Робітник** (не Worker Pay) |
| Прибиральниці | У базі **не знайдені** (пошук за ім’ям/посадою) |
| Payslips | На вантажників (id 30–32) — **0** відомих payslip |
| Робітник type | `default_struct_id` **немає** — окрема структура під денну ставку ще не зведена |

**Висновок:** картки людей частково заведені; процес нарахування (дні × ставка → Зарплата vs лише проводка в Бухобліку) **не налаштований**.

## Варіанти (після відповіді клієнта)

1. **Зарплата (hr_payroll):** нова/розширена структура (напр. фікс за день або за місяць за табелем), payslip, проводки через `hr_payroll_account`.
2. **Лише бухоблік:** Employee довідково; нарахування — ручний журнал / щомісячний запис витрат без payslip (якщо виплати ведуть зовні).

Без `--apply`, поки немає рішення клієнта.
