# Відрядна зарплата (Worker Pay)

Скрипти, якими налаштовано відрядну зарплату в Odoo. Усі ідемпотентні: без
`--apply` лише показують, що змінять.

| Скрипт | Що робить |
| --- | --- |
| `npm run payroll-rules` | По одному правилу `п-…` у структурі Worker Pay на кожен цех з `src/workcenters/canon.ts` |
| `npm run payroll-default-worker` | Поле «Робітник за замовчуванням» на робочому центрі + автоматизація, що ставить його в «Призначено» нових робочих замовлень |
| `npm run payroll-contracts` | Працівникам «(Цех …)»: тип структури Worker і дата початку контракту |

Запис: `npm run payroll-rules -- --apply`.

## Як рахується

Сума за цех = Σ `qty_produced` × `x_studio_piece_rate_2` (Price Rate операції)
по робочих замовленнях цього цеху у стані `done`, завершених у періоді листка
(`date_finished`). Повну суму отримує кожен працівник з `employee_assigned_ids`.

Керівник потрапляє в «Призначено», коли закриває операцію, — для нього просто
не створюють листок. Не рахуються через Odoo: див. `EXCLUDED_EMPLOYEES` у
`config.ts`.

Новий цех: додати в `canon.ts` і `PAYROLL_SHOPS`, запустити скрипти з `--apply`.
