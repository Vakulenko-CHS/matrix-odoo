# Формат: накладки + кольоровий ламінат-лист

**Aliases / find me:** накладки, nakladky, ламінат кольоровий, Ширина Кромки, `Накладки.tsv`, overlay, colored laminate sheet.

Джерело правди для sync: `temp/Накладки.tsv`  
Скрипт apply/check: `src/tools/sync-nakladky.ts`  
Список точкового фіксу (19 диванів): `temp/nakladky-fix-list.md`  
Білий лист (окремо): `temp/Ламінат.tsv` + `src/tools/sync-laminate-sheet-boms.ts`

## Порядок створення (завжди)

1. Attr **`Ширина Кромки`** = `20мм`, `40мм` (якщо ще нема).
2. **`[Кромка]`** = `%Колір Ламінату%` × `%Ширина Кромки%`  
   Ім’я: `[Кромка] (Венге, 20мм)`
3. **`🧩[Ламінат кольоровий - лист]`** = `%Ламінат Розмір%` × `%Колір Ламінату%`  
   Ім’я: `🧩[Ламінат кольоровий - лист] (1006x198, Венге)`  
   **Не** писати розмір у назві шаблону (архівовано `… 1006x198` тощо).
4. BOM листа (нарізка) ← колонки TSV C–G.
5. **`🪤[Накладка] {Модель}`** = `%Колір Ламінату%`  
   Ім’я: `🪤[Накладка] Д.Леон-Люкс (Венге)`  
   BOM споживає лист(и) того ж кольору ← колонка B (+ qty).

Білий лист **окремо**: `🧩[Ламінат - лист] (%Ламінат Розмір%)` + `[Ламінат] (Білий)` / `[Кромка] (Білий, 20мм)` — див. `Ламінат.tsv`.

## TSV `temp/Накладки.tsv`

| Col | Зміст | Куди |
|-----|--------|------|
| A | Модель накладки (коротко) | → `🪤[Накладка] {A}` (+ колір) |
| B | Розмір листа (`1006x198` або `240x303-1шт`) | → attr `Ламінат Розмір`; qty з суфікса `-Nшт` |
| C | м² ламінату | BOM листа → `[Ламінат] (колір)` uom `m²`, op Порізка |
| D | грн Порізка | `x_studio_piece_rate_2` на op Порізка |
| E | грн Поклейка (`null` = без кромки) | op Поклейка |
| F | м кромки (`null` = БК) | BOM листа → `[Кромка] (колір, ширина)` uom `m` |
| G | грн Присадка (`null`/`?` = skip) | op Присадка |
| H | грн Склейка накладки (рідко) | op на BOM накладки, Цех 3-2 |

Рядки без A (лише розмір) = додаткові розміри листів (смужки тощо).

### Ширина кромки

- Default **20мм**.
- **40мм** лише: `Д.Елегант (32)` → розмір `1090x250`, `Уг.Елегант(32)` → `1660x250` (жовті в TSV).

### Кольори

Attr **`Колір Ламінату`** (id=5). У базі зараз: `Венге`, `Трифе`, `Дуб крарт`, `Білий` (+ placeholder `❌` — **не** вішати на кольоровий лист/накладку).

TSV пише «Трюфель» / «Дк Крафт» — **канон Odoo** = `Трифе` / `Дуб крарт` (не перейменовувати без окремого таску).

«Кольоровий» = усі реальні значення кольору (без `❌`).

## Імена продуктів (канон)

```text
🧩[Ламінат кольоровий - лист] (%Ламінат Розмір%, %Колір Ламінату%)
[Ламінат] (%Колір Ламінату%)
[Кромка] (%Колір Ламінату%, %Ширина Кромки%)
🪤[Накладка] {Модель} (%Колір Ламінату%)
```

Розмір завжди latin `x` (`1006x198`), не кирилиця `х`.

## BOM листа (Цех №3-0)

Workcenter: `Цех №3-0 ЛДСП (Нарізка Ламінату)` (id=30).

| Op seq | Назва | piece_rate | Споживає |
|--------|--------|------------|----------|
| 1 | `Операція (Цех №3-0) Порізка - {product}` | col D | `[Ламінат] (колір)` qty=C |
| 2 | `… Поклейка - {product}` | col E | `[Кромка] (колір, width)` qty=F (якщо не null) |
| 3 | `… Присадка - {product}` | col G | — (якщо не null) |

`mrp.bom.line.operation_id` = «Спожитий в операції».

Один BOM на **variant** листа (`product_id` = конкретний size×color), `code` = display name.

## Команди

```bash

npx ts-node --transpile-only src/tools/sync-nakladky.ts --check

# apply (live Odoo — .env.local / ODOO_*)
npx ts-node --transpile-only src/tools/sync-nakladky.ts --apply
npx ts-node --transpile-only src/tools/sync-nakladky.ts --apply --phase=1,2,3

# white sheets
npx ts-node --transpile-only src/tools/sync-laminate-sheet-boms.ts --check
npx ts-node --transpile-only src/tools/sync-laminate-sheet-boms.ts --apply
```

Phases sync-nakladky: `1` attr width → `2` кромка+remap → `3` reshape sheet attrs → `4` sheet BOMs → `5` overlays → `6` archive size-in-name leftovers.

**Не писати в Odoo** без явного apply / дозволу юзера. Credentials: `.env.local` (не комітити; `.env` часто порожній-gate).

## Відомі дірки / обережно

- TSV моделі без накладки в базі: Берлін, Барселона, Мадрід(Сігма), Престиж, Малібу, Смужки…
- Диванні `tmpl::` BOM без кольору, що тягнули старий Леон-Люкс → тимчасово `Венге`; треба variant-level remap.
- Додавання attr на tmpl з `asComp>0` ламає старі `product.product` → обов’язково remap BOM lines.
