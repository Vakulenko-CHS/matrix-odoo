# Agent logs (`<repo>/.ai/logs/`)

**Do not read this folder wholesale.** Start at [../CONTEXT.md](../CONTEXT.md) → **Log index**.

## Rules

1. Open only log files whose **Topics** match the current task.
2. New session notes → prepend to the matching log (newest first).
3. New topic → new `*.md` file + new row in CONTEXT **Log index**.
4. Keep entries short: summary, files, push, git hash.

## File naming

| Pattern | Use |
|---------|-----|
| `<topic>.md` | Long-running area (`search.md`, `collections.md`) |
| `YYYY-MM-DD-<slug>.md` | One-off or cross-cutting session |
