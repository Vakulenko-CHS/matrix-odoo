# T-VOL-01 — текст для клієнта (Telegram / email)

Скопіюйте й за потреби підставте ім’я. Файл для таблиці: **`divany-obem-vaga.tsv`** (поруч із Specs у `furniture/reference/`).

---

Добрий день.

Для модуля **«Автотранспорт»** в Odoo потрібні **об’єм** і **вага** кожної моделі **готового дивана** (одна строка = одна назва з нашого списку моделей, як у таблиці Specs).

Надсилаю файл **`divany-obem-vaga.tsv`** — три колонки:

1. **назва_дивана** — уже заповнена (84 моделі з Specs; позиції зі статусом «Відміна» не включали).
2. **об'єм_m3** — прохання заповнити об’єм **в м³** (краще з крапкою: `1.25`).
3. **вага_kg** — прохання заповнити вагу **в кілограмах** (ціле або з десятковими: `85` або `85.5`).

**Як заповнити:** відкрийте файл у Google Таблицях / Excel (імпорт TSV, роздільник — табуляція) або скопіюйте вміст у таблицю. Не змінюйте назви в першій колонці — лише допишіть об’єм і вагу.

**Що маємо на увазі під об’ємом/вагою:** упакований готовий диван, як ви реально вантажите в машину (той варіант, який найчастіше їде клієнту). Якщо для однієї моделі є суттєво різні комплектації — напишіть у коментарі до рядка або узгодимо окремо.

Коли заповните — надішліть файл назад. Ми **одним завантаженням** занесемо значення в Odoo.

Дякую.
