## B. Значення атрибута «Тканина» (три різні історії)

### B1. `validate` / `validate-all` — служебні з імпорту

| | |
|--|--|
| **Що це** | Назви з пайплайну перевірки markdown→Odoo (як у `exports/*.json`), не назви тканин від клієнта |
| **Де в базі** | PAV **714** (314 ptav), PAV **713** (184 ptav) |
| **Чи є в замовленнях / MO / складі** | **Ні** (0 рядків SO, 0 MO, 0 залишків з такою тканиною в назві варіанта) |
| **Якщо прибрати** | Зникає з випадаючого «Тканина» при конфігурації дивана; **652+** теоретичних варіантів без цих ptav лишаться недоступні — це ОК, їх ніхто не замовляв |
| **Ризик** | Повторний `import-json` зі старих export знову створить значення — треба чистити спеки або export |

### B2. `Синтетика` — **не** те саме, що validate

| | |
|--|--|
| **Що це** | Загальна мітка «сynthetic» у **старих BOM-спеках** (багато `exports/`), коли замість конкретної тканини (Рене 20, Грегор 12…) стояла категорія. **Немає** в каноні `right_names.md` — це не SKU Matrix |
| **Де в базі** | PAV **718**; **113** ptav на **109** шаблонах (чохли, подушки, ~86 диванів тощо) |
| **Чи є в замовленнях / MO / складі** | **Ні** — 0 рядків sale.order, 0 MO, 0 quants з «Синтетика» в назві варіанта (перевірено 2026-11-05) |
| **Якщо прибрати** | Клієнт/менеджер **не зможе** обрати «Синтетика» в Odoo при продажі; варіанти типу `Диван Сітті (Синтетика, …)` перестануть існувати як комбінація — **на реальні замовлення це не вплине**, бо таких замовлень немає |
| **Якщо залишити** | У списку тканин лишається «зайва» опція; плутанина з реальними тканинами; зайві комбінації варіантів |
| **Рішення** | Окремий чекбокс від validate: можна **не чіпати**, поки не вирішите, чи потрібна окрема «синтетична» тканина як продукт `[Тканина] (…)` |

**Не плутати:** **Заказна Тканина** (pav id=4) — робоча placeholder-назва від клієнта, **не** видаляти без окремого рішення.

## Свідомо не пропонуємо архівувати

1. **4131** ptav з `price_extra=100` (тестова доплата +100 ₴) — потрібен **reset на 0** або per-sofa extra, не delete (колега вже закрила логіку в T-PRC-01).
2. **83** шаблони диванів з `list_price=1` — T-COST-01.
3. **4** чернетки `sale.order` (ФОП Максим Самойленко) — робочі чернетки.
4. **~300** скасованих MO з липня 2026 — історія Odoo, не блокують роботу.
5. Quants на архівному **[Войлок] (1.40)** — відомо після T-FELT-01 (ACL).
