## Qty що залежить від розміру (Террі газ, з клієнта)

Не копіювати 90×200 сліпо.

| | 80/90 ширина | 120 ширина |
|---|---|---|
| ДСП / ДВП дно | 2.75 / 1+2 | 3.1 / 1.1+2.8 |
| ламінат ширина листа | 80→820, 90→920, 120→1220 | |
| ламінат довжина | 190→1971, 200→2071 | |
| поролон 20/10 кг | 0.704 / 0.26 | 0.75 / 0.3 |
| тканина | 2.40 | 3.30 |
| амортизатор | 450 | 750 |
| Цех 9 грн | 324 | 372 |

Флізелін / картон **по розмірах як у клієнта** (Q6, 2026-11-09): не уніфікувати 3.0/3.5 і 2.0/2.9 без нової вказівки.

Газ: `Кроватний гідравл б/б` + амортизатори. Без газу — не ставити гідравліку.

Каркас ламельний купується в 9, не ріжеться в 1–4.

Бортик DSP 0.4 / DVP 0.3 / тканина 0.95 — однакові на Террі газ у клієнта.

## Чеклист `fixed.md` (ліжко)

1. Заголовок: `[Товар] (повна назва)` + блок атрибутів `✅`/`❌` узгоджений з KNOWLEDGE (ізголов’я на чохлах; бортик/ламель — Террі газ або сирий).
2. Інструкція `@Бортик=` / `@Ізголовье=` лише на **цех 9**, не «розмазувати» по каркасу.
3. Цехи `2-4`, `4-4`, `6-1` — окремі блоки бортика (еталон Террі газ).
4. `# Цех` — коди з `src/workcenters/canon.ts` (formatter/`ai-check`).
5. Ізголов’я: окремий `🧩[Ізголовье в тканині - нарізані матеріали]`, не «і може бути» в чохлі.
6. `npm run ai-check -- --as-is path/to/fixed.md` після правки.

## Порядок імпорту ліжок у Odoo

1. **T-WC-01** — `ensure-workcenters --apply` (2-4, 6-1, … у `canon.ts`).
2. Каталог напівфабрикатів / сировини (імпорт створює відсутні з BOM).
3. Шаблони з `tracking=serial` з першого дня (T-SER).
4. BOM + операції (`import` / batch) — один slug = один шаблон (Q9: газ ≠ без газу).
5. Ламінат/накладки вже **купівля** (T-LAM) — не очікувати ВНЗ на 3-x.
